# 05 — Instalación de Odoo

1. Ejecuta el instalador (`.exe`) como **Administrador**.
![Ejecutar .exe](../assets/img/05-instalacion_odoo/01_ejecutar-exe.png)
2. Acepta la licencia y elige **ruta de instalación**.
![Aceptar licencia](../assets/img/05-instalacion_odoo/02_aceptar-licencia.png)
![Ruta instalación](../assets/img/05-instalacion_odoo/02_ruta-instalacion.png)
3. Si se solicita, configura la conexión a **PostgreSQL**.
4. Completa la instalación y finaliza el asistente.
![Asistente Odoo](../assets/img/05-instalacion_odoo/04_asistente-finalizado.png")
![Finalizar](../assets/img/05-instalacion_odoo/04_finish.png)

> Resultado esperado: Odoo instalado, acceso a accesos directos/servicio.
